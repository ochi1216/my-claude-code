# みせノート自動化：ネットワーク許可の手順

このセッションはクラウド上の隔離環境で動いており、`misenote-demo.vercel.app` への通信が
環境のネットワーク設定でブロックされています（2026-10-04 確認、HTTP 403）。

## 手順（画面遷移）

1. セッション画面の上部タイトルバーにある「クラウド環境」メニューを開く
2. 「Edit（編集）」を押す
3. 「Network access（ネットワークアクセス）」を **Custom** にする
4. 「Allowed domains（許可ドメイン）」に `misenote-demo.vercel.app` を追加する
5. 「パッケージマネージャーの既定リストを維持」にチェックを残したまま保存する
6. 新しいセッションを開始するか、このセッションに「許可した」と返信する

公式説明: https://code.claude.com/docs/en/cloud-environments#network-access

## 補足

- 許可するのはこの1ドメインだけで十分です（他は開けなくてOK）
- 許可後、まず「ダッシュボードの前日売上を読むだけ」を1回試します（書き込みなし）
