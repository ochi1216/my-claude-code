# BBT RTOCS Organizer

BBT「大前研一ライブ」のRTOCSコーナーの講義動画を自動取得し、Gemini APIで要約してHTMLレポート化するツール。

## 必要要件

- Python 3.9以上
- Google Chrome
- Gemini APIキー

## セットアップ手順

1. 依存パッケージをインストールする。

   ```
   pip install -r requirements.txt
   ```

2. スクリプト実行前に、リモートデバッグを有効にした状態でChromeを起動しておく。本スクリプトはChromeを新規起動せず、既存のChromeインスタンスにポート9222で接続する（`RTOCSManager.connect_chrome`）。

   ```
   chrome.exe --remote-debugging-port=9222 --user-data-dir="C:\ChromeDebugProfile"
   ```

3. 環境変数 `GEMINI_API_KEY` にGemini APIキーを設定する（設定後は新しいターミナルを開いて実行する）。

   ```
   setx GEMINI_API_KEY "your-api-key-here"
   ```

4. `BASE_DIR`（`rtocs_organizer_20260711_01.py` 内で `C:\Users\nx023836\Documents\PythonScripts\bbt\RTOCS_organizer` にハードコードされている）配下の `data\category_map.json` に、年度とbbt757のカテゴリID(`subCatId`)の対応表を用意する。このファイルが無いと、import修正後は起動時のGUI (`RTOCSConfigGUI`) が `category_map.json` の読み込みで `FileNotFoundError` を起こす。

   ```json
   {
     "2026": {"id": "xxxxx"},
     "2025": {"id": "yyyyy"}
   }
   ```

5. スクリプトを実行する。

   ```
   python rtocs_organizer_20260711_01.py
   ```

## 既知の制限（今回のスコープ外）

- `BASE_DIR` が特定ユーザー名のパスでハードコードされている。
- `RTOCSConfigGUI` クラスがファイル内で2重定義されており、後方の定義が前方を上書きしている（デッドコードあり）。

## RTOCS 統合ダッシュボード（俯瞰・傾向分析＋一気通貫戦略策定）

蓄積したRTOCSデータを横断的に分析するツール一式。`rtocs_organizer_20260711_01.py` と同じフォルダに置いて使う（`data/` フォルダを共有する）。

- `rtocs_index.py` — `data/JSON_lake` から軽量なケース一覧（`data/rtocs_index.json`）を増分構築する共通部品
- `strategy_prompts.py` / `strategy_engine.py` — 企業名を1つ入力すると「会社分析→直近ニュース収集(英/日/中)→アナリスト洞察収集→マクロ・技術トレンド分析→株式市場分析→業界・競合分析→類似RTOCS事例選定→他業種事例分析→課題分析→戦略策定→前回分析との比較(過去レポートがある場合のみ)」を自動で実行するパイプライン。株式データはAIが推測したティッカーが対象企業の英語社名と一致するかを自動チェックし、一致しない候補は自動的にスキップする
- `strategy_report.py` — 分析結果を1枚の自己完結HTMLレポートに整形
- `rtocs_dashboard_20260719_03.py` — 上記をまとめたStreamlitダッシュボード本体（最新版。変更履歴は [`CHANGELOG.md`](CHANGELOG.md) を参照）

### 起動方法

```
pip install -r requirements.txt
streamlit run rtocs_dashboard_20260719_03.py
```

ブラウザが自動で開き、以下の4タブが表示される。

1. **📋 一覧・検索** — 従来通り、企業名・キーワード・業界でRTOCSを検索し、HTML/PDFを開く
2. **📈 傾向分析** — 業界分布の年次推移、キーワード頻度・トレンド、地域ミックス、複数回登場企業の一覧をグラフで俯瞰。「AI俯瞰総評」ボタンで、全ケースをGeminiに読ませた傾向コメントも生成できる
3. **🎯 戦略分析** — 任意の企業名を入力すると、蓄積RTOCSをケースライブラリとして活用しながら一気通貫で戦略分析レポート（HTML）を生成する。会社分析の直後に、Google Search Groundingで英語・日本語・中国語の企業名表記から直近12ヶ月のニュースを検索するステージ、続けてセルサイドアナリストの見解・決算説明会でのマネジメント発言・市場評価と自己認識のギャップを検索するステージ、続けて業界全体・時代全体の構造変化（AI化・地政学・規制・サプライチェーン）を検索するステージが入る（株価の生数値だけでなく市場参加者の解釈と時代の変化を戦略提言に反映する）。株式市場分析は、これらニュース・アナリスト洞察・マクロトレンドの結果を統合し、単なる現状データの説明ではなく「今後の株価の方向性」「想定リスク」「今後のカタリスト」まで踏み込んで分析する。「経営の制約条件（任意）」を入力すると、AIには分からない実行可能性の制約（負債covenant、取締会の性質等）を課題分析・戦略策定の全ステージで必須順守として反映できる。戦略策定はブルーオーシャン戦略・ジョブ理論・アンゾフの成長マトリクス・ポートフォリオ経営(BCG的発想)の4フレームワークを横断的に検討し、3つの戦略それぞれに「保守的／野心的／破壊的」の大胆さのモードを必須で割り振る（破壊的モードは「今日創業するなら」等の制約外し思考を明示的に使う）。類似RTOCS事例の選定は同業種への偏りを避け、構造課題が近ければ異業種の事例も積極的に選ぶ（🌉異業種バッジで表示）。戦略提言全体には「悪魔の代弁者」による反証所見が必ず付く。「通常」（gemini-2.5-flash、数十円/回）と「ディープ」（gemini-2.5-pro＋戦略の批判・改訂パス、数百円/回）の2モード。レポート生成後は「💬 レポートについて質問する」チャットで、生成済みの分析結果を文脈にした深掘り質問ができる（1問ごとに追加コストが発生）。「分析前に中間結果を確認する」チェックボックス（既定はOFF）をONにすると、会社分析〜他業種事例分析までの前半ステージだけを先に実行して内容を表示し、追加コメント・修正指示を入力してから課題分析・戦略策定（後半）を実行できる。各ステージには「出典確度」（high/medium/low、実データ・検索結果に基づくか、AIの知識・推論に基づくかの目安）が付記され、戦略提言のうちM&A等の大規模な打ち手については既存の財務データと比較した資金的な実行可能性の注記が自動で付く。各戦略には「最初の90日／1年後のマイルストーン／3年後のビジョン」の3つの時間軸のロードマップが示される。また、同一企業を過去に分析したレポートが見つかった場合は、分析完了後に前回との比較（課題の改善状況・新たな課題・戦略の継続性）を自動生成する（初回分析時は自動でスキップ）
4. **🗂 分析履歴** — これまでに生成した戦略分析レポートを一覧表示し、企業名で検索した上でレポートを開く・ダウンロードできる。生成した分析結果は`data/strategy_reports/`フォルダにHTML（＋構造化データのJSON）として自動保存されており、上書き・削除はされないため、いつでもこのタブから再アクセスできる

### 注意点

- 上場企業は `yfinance` で株価・財務データ（手元資金・総負債・負債資本比率・フリーキャッシュフローを含む）を自動取得するが、未上場企業は定性分析のみとなる（自動判定・自動フォールバック）。これらの財務データは「M&Aや大規模投資に振り向けられる資金余力」の所見として戦略提言に反映される
- 株式市場分析カードには、実際に取得したティッカー・企業名とYahoo Financeの該当ページへのリンクが必ず表示される。AIが推測したティッカーが対象企業の英語社名と一致しない場合は⚠️警告が表示されるので、数値を意思決定に使う前に必ずリンク先で裏取りすること
- 株式市場分析は単なる現状データの説明ではなく、直近ニュース・アナリスト洞察・マクロ/技術トレンドを統合した「今後の株価の方向性（強気/中立/弱気/不透明）」「想定される主要リスク」「株価を動かしうる今後のカタリスト（決算発表等）」まで分析する
- 各分析ステージが失敗しても処理は止まらず、レポート内に「取得失敗」として表示される（部分的なレポートは必ず生成される）
- AIの知識に基づく分析は不確実な場合があるため、レポート内の記述は参考情報として扱い、重要な意思決定の前には要確認
- 直近ニュース収集はGeminiの検索グラウンディング機能（`google-genai`パッケージ経由）を使用するベストエフォート実装。この1ステージだけが失敗しても、ニュースセクションが空になるだけで他の分析ステージには影響しない。ニュース・アナリスト洞察・マクロトレンドの各カードには、検索が実際に参照したページへのリンクが「参照元」として表示される（グラウンディングが機能しなかった場合は表示されない）
