# 京都市図書館 新着図書サマリ（library_management）

京都市図書館の「新着図書」ページを分類ごとに巡回取得し、書籍名・作者・出版社・出版年月を
まとめたレスポンシブHTMLサマリを生成するツール。前回実行時との冊数差分・新着件数を
JSON履歴として保持し、GUI（Tkinter）上でカテゴリ選択・出版年月フィルタ・新着のみ抽出を
指定できる。

## 必要要件

- Python 3.9以上（Windows想定。GUIにTkinter、完了後のHTML自動オープンにOS標準ブラウザを使用）
- インターネット接続（京都市図書館サイトへのアクセス）

## セットアップ手順

1. 依存パッケージをインストールする。

   ```
   pip install -r requirements.txt
   ```

2. スクリプト内の定数を環境に合わせて確認する（`Library_new_stock_summary_20260401_01.py`）。

   - `OUTPUT_DIR`：生成したHTMLサマリの出力先ディレクトリ（現状 `C:\Users\nx023836\Nexperia\My Private - Documents\Summary` にハードコード）。
   - `HISTORY_FILE`：前回冊数・既知書籍を記録する `category_history.json`。スクリプトと同じフォルダに自動生成される（`.gitignore`でコミット対象外）。

3. スクリプトを実行する。

   ```
   python Library_new_stock_summary_20260401_01.py
   ```

   分類選択GUIが起動するので、対象分類・出版年月フィルタ・「新着のみ抽出」の有無を選び「抽出開始」を押す。完了後、生成されたHTMLサマリが既定のブラウザで自動的に開く。GUIを閉じるとプログラムを終了する。

## 自動実行（サイレント）モード

Windowsタスクスケジューラ等からの無人実行用に、起動引数 `--auto` に対応する。

```
python Library_new_stock_summary_20260401_01.py --auto
```

GUIを表示せず、「全カテゴリ対象」「新着のみ抽出」「出版年月フィルタなし」で1回だけ抽出・HTML生成を行い、ブラウザは開かずに終了する。

## 生成されるHTMLサマリの機能

- 列（分類・書籍名・作者・出版社・出版年月）ごとの絞り込み検索、列ヘッダークリックでのソート
- 書籍名・作者・出版社クリックで京都市図書館OPACの該当キーワード検索を別タブで実行
- 各書籍の「🔍 検索」リンクから、note/Qiita/YouTube/flier等の優良サイトに限定した書評・要約のGoogle検索を実行
- 「キープ」チェックボックス（ブラウザのLocalStorageに保存。次回生成したサマリを開いた際も復元される）

## 生成済みサマリの削除（ごみ箱移動）

`Summary`フォルダには実行のたびにHTMLサマリが増えていくため、
`Library_stock_summary_remover.bat`をダブルクリックすると、
`Library_new_stock_summary_*`に一致するファイルをまとめてごみ箱へ移動する
（完全削除ではないため、誤操作時もごみ箱から復元できる）。Tool Launcherにも
「図書館サマリ削除（ごみ箱移動）」として登録済み。

## 既知の制限（今回のスコープ外）

- `OUTPUT_DIR` が特定ユーザー名のパスでハードコードされている。
- Tkinter（GUI）とOS標準ブラウザの自動起動に依存しており、GUIのない環境（サーバー等）では `--auto` モードのみ使用可能。
