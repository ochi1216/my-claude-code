# outlook_total_organizer の軸（2026-10-04 越智さん確定）

## 軸
**越智さんの判断（意思決定）を支える。** メールは、判断の材料と証拠として扱う。

## 3つの時間軸
| 時間軸 | 問い | 主な材料 |
|---|---|---|
| 毎日 | 私の判断を待っている案件を落としていないか | 受信メールのうち、承認・決裁・相談・質問が自分宛てのもの |
| 毎週 | 判断が必要になりそうな兆しはどこか | 停滞・催促・長期沈黙・急な炎上、プロジェクト/スタッフの動き |
| 四半期 | どんな判断をし、何が起きたか | 自分の送信メール（実行・判断したこと）と主催会議 |

## 判断基準
- 新機能は、上の3つの問いのどれに答えるかを先に書く。答えないものは作らない。
- 軸の外の機能（広告抽出、RSS抽出、迷惑メール既読化など）は「道具」として残し、目立たない場所に置く。削除はしない。

## 制約（変わらないもの）
- Outlook（win32com）前提。外部SaaSへ送信しない。新規IT権限は申請しない。メールを自動送信しない（下書きまで）。
- 1回100円以上の見込みのAI処理は、実行前にコストを表示する。
- 起動時に最初に開くタブは変えない（越智さん回答 2026-10-04）。
