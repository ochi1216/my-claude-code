## [20260722_01] - 2026-07-22

**追加ファイル:** `project_cost_analyzer_20260722_01.py`, `requirements.txt`, `README.md`, `run_dashboard.bat`

初版。Project CostのKOB1シート（SAPプロジェクトコスト実績明細）を読み込み、プロジェクト単位で
コスト分析を行うStreamlitダッシュボードを新規作成。

- Supabase等の外部サービスへデータをアップロードする方式を検討したが、社内の機密性の高い
  コストデータであることと、環境の自動判定（安全分類器）が外部への一括データ送信をブロック
  したことから、ローカル環境で完結する構成（Excel直接読み込み→ローカル集計→Streamlit表示）
  に方針転換した
- Project Name / Fiscal Year / Project status / Cost Category での絞り込み、プロジェクト別・
  期間別・Cost Category別・Cost Element別・Function別の集計、明細テーブル表示、Excel出力に対応
- Windows用起動バッチ`run_dashboard.bat`を追加。フォルダ内の`project_cost_analyzer_*.py`を
  ファイル名降順（`dir /o-n`）で判定し、最新リビジョンを自動的に起動する（バージョンアップ時に
  バッチファイル自体の書き換えは不要）

## [20260722_02] - 2026-07-22

**追加ファイル:** `project_cost_analyzer_20260722_02.py`（`20260722_01`からのコピー＋機能追加。旧版はそのまま残置）

元データが18MB・8万行超あり、Excelパースに15〜17秒かかっていた。今後頻繁に修正・再起動を
繰り返す運用を見込み、ユーザーより「元データに変更がなければ次回起動を高速化したい」との
要望があり対応:

- パース結果を「元ファイルの隣（パス指定時）」または「OS一時フォルダ（アップロード時）」に
  `.kob1_cache/` としてpickle保存し、元ファイルのパス・更新日時・サイズが変わっていなければ
  次回起動時にそこから読み込む（実測: 初回15〜17秒 → ツール再起動後のキャッシュ利用時は約2.5秒）。
  キャッシュはリポジトリ外に置き、機密データが誤ってGit管理下に入らないようにしている
- 同一Streamlitプロセス内では`st.cache_data`により、フィルタ操作のたびの再読み込みも回避する
  （実測: 約1秒）
- 元データを更新すると更新日時・サイズの変化により自動的にキャッシュが無効化される。古い
  キャッシュファイルは新しいキャッシュの保存時に自動削除し、ディスク容量の圧迫を防止
- サイドバーに「キャッシュを無視して再読み込み」チェックボックスと、キャッシュ利用状況・
  保存先の表示を追加

## [20260722_03] - 2026-07-22

**追加ファイル:** `project_cost_analyzer_20260722_03.py`（`20260722_02`からのコピー＋機能追加。旧版はそのまま残置）

Step1「単一プロジェクトのコスト分析特化」として、PM・ファンクションマネージャー・製品部
ディレクターの3視点を踏まえた機能拡充を実施（4は予算対比で今回は保留）:

- 画面を3タブ構成に再編:
  - 🏛 事業部俯瞰: 全Profit Center（R03/R04/R07/R0N/R0S/R19）を横断俯瞰。事業部別サマリー表
    （総コスト・プロジェクト費/非プロジェクト費・プロジェクト数・平均/プロジェクト・内部労務比率）、
    プロジェクト費vs非プロジェクト費（`Project status = Other IO`で判定）の比較を追加
  - 🧭 プロジェクト深掘り: 単一プロジェクトのカルテ（累計コスト・内部労務比率・参加組織数・
    対象期間）、バーンチャート（月次コスト棒＋累計折れ線の二軸）、Function別/Organization別
    内訳、外部購買明細（PO単位）、工数投下(Man month, FY2026限定)を追加
  - 🔧 ファンクション横断: Function（職種）を選ぶと、どのプロジェクトに・誰が(Resource name)・
    いくら/何MMチャージしているかを横断表示
- 通貨表示を調査のうえUSDに統一。`Val/COArea Crcy`はSAPの統制領域通貨で元々単一通貨
  （ブック内「Cost by nature」シートが"Cost in $"と明示、Company Code別の金額規模からも
  現地通貨混在でないことを確認済み）のため換算は行わず、UIにUSDである旨を明示するのみ
- サマリーカードを「対象プロジェクト数 / 対象総コスト(USD) / 対象期間」の3枚に変更し、
  「明細行数」は削除
- 期間別コスト推移を折れ線から棒グラフに変更し、「積み上げ表示」トグル（Cost Category /
  Profit Center / PM cost categoryを軸に選択可）を追加
- Cost Category別・PM cost category別・Function別・Cost Element別（上位15）の内訳グラフに、
  個別に棒グラフ⇔円グラフを切り替えられるトグルを追加（円グラフはマイナス値＝会計調整分を除外）
- サイドバーのファイルパス・フィルタ選択（Profit Center/Fiscal Year/Project status）・
  積み上げ設定を、スクリプトと同じフォルダの`.pca_settings.json`に保存し、ツールを再起動
  しても前回の設定のまま復元されるようにした（`.pca_settings.json`はデータそのものは含まない
  設定値のみのため、`.kob1_cache/`と異なりGit管理下でも問題ないが、環境依存のローカルパスを
  含むためリポジトリには含めない運用とする）
