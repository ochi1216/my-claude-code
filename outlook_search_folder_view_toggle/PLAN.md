# Outlook 検索フォルダー 表示モード一括制御ツール — 改訂プラン v2

設計方針は変更なし：「検索条件は不変、表示モードだけを全体制御」。
既存の `NTAN`・`Iketomo`・`Flags` 等の検索フォルダーを維持したまま、未読／すべてを
一斉に扱う。v1からの変更点は、実装前に潰しておくべき3つの事故要因
（他フォルダーへの波及／`Filter`の反映条件の不確定／起動直後の初回フォルダーが
取り残される）への対処を組み込んだこと。

| 項目 | 設計 |
| ---- | ---- |
| 制御対象 | 越智さんが登録した検索フォルダーだけ |
| 制御内容 | 一覧ビューに未読フィルターを重ねる／解除する |
| 非対象 | 検索条件、メール本文、既読状態、移動・削除、**未登録フォルダーの表示（専用ビュー化で保証）** |
| 永続化 | 最後のモードと対象フォルダーをWindowsユーザー領域へ保存 |
| 操作 | `未読モード`・`すべてモード` をクイックアクセスツールバーへ配置（**初回のみ手動でピン留め**） |

## 実装フェーズ

### フェーズ0（新設）：登録前診断 ＋ 専用ビュー化

対象フォルダーを制御下に置く前に、必ずこの処理を先に通す。

1. 対象フォルダーの現在のビューが「この種類のすべてのフォルダーと共有」設定に
   なっていないかを確認する。共有になっていた場合、そのままフィルターを
   書き換えると受信トレイなど無関係なフォルダーの表示まで一緒に変わってしまう
   ため、放置しない。
2. 現在のビューを複製し、「このフォルダーだけ・自分だけ」に閉じたビューを
   新規作成する。以後はこの複製ビューだけを操作対象とする。
   これにより、以降の操作がどれだけ乱暴でも他フォルダーへは絶対に波及しない。
3. あわせて、フィルターの変更が「かけている間だけ画面に反映され、
   何もしなければ元の状態のまま残る」タイプか、「変更するとその場に
   固定されて残る」タイプかを、1フォルダーだけで実地に確認する
   （パイロット環境のOutlookバージョンでどちらの挙動かを見る）。
   結果によって後続フェーズ5の作り込み量が変わる：
   - 前者（かけている間だけ反映）なら、フォルダー切替のたびに
     フィルターを掛け直すだけでよく、「元に戻す」処理はほとんど不要
     （何も固定していないので、放っておけば元通り）。
   - 後者（固定される）なら、フェーズ5の「元のビューを保存して戻す」
     復元処理が必須になる。

### フェーズ1：検索フォルダー台帳の取得

現在存在する検索フォルダーの名前、Store ID、Entry IDを抽出する。
`Store.GetSearchFolders` を使うため、受信トレイ配下の物理フォルダーとは
混同しない。複数のメールボックス（共有メールボックスやPST）を開いている
場合に備え、`Session.Stores` を一つずつ確認してから、それぞれの
`GetSearchFolders` を呼ぶ。
[Store.GetSearchFolders](https://learn.microsoft.com/en-us/office/vba/api/outlook.store.getsearchfolders)

### フェーズ2：対象登録機能

各お気に入り検索フォルダーを開き、`この検索フォルダーを管理対象に登録` を
一度実行する。この実行の中でフェーズ0の専用ビュー化もあわせて行う。
フォルダー名だけでなく固有IDで登録するため、同名フォルダーがあっても
誤作動しない。

### フェーズ3：グローバルモード機能

`未読モード` は「未読だけ表示」の表示フィルターを適用、`すべてモード` は
元の表示フィルターへ復元する。検索フォルダー固有の分類条件は、下層の
検索条件としてそのまま残る。フェーズ0で用意した専用ビューに対してのみ
操作するため、他フォルダーへの影響はない。
[View.Filter](https://learn.microsoft.com/en-us/office/vba/api/outlook.view.filter)

### フェーズ4：フォルダー移動時の自動適用

Outlookでは「フォルダーを切り替えた」ことを検知する仕組みは、
開いている画面（ウィンドウ）ひとつひとつに対して用意する必要がある。
具体的には：

- Outlook起動時に、その時点で開いている最初の画面に対して見張り役を1つ立て、
  **その場で即座に保存済みモードを適用する**（ここが v1で抜けていた部分。
  これが無いと、Outlookを開いて一番最初に表示されるフォルダーだけ、
  前回選んでいたはずのモードが反映されないまま残ってしまう）
- 2枚目以降のOutlookウィンドウが開かれたときは、その都度同じ見張り役を
  追加で立てる
- 各見張り役は、自分が担当する画面でフォルダーが切り替わるたびに、
  「これは管理対象の検索フォルダーか」を判定し、対象であれば
  保存済みの全体モードを再適用する

これで `NTAN` で未読モードを選んだ後、`Flags` や `Iketomo` を開いても、
そしてOutlookを再起動して最初に開いた画面でも、常に同じモードから始まる。
[Explorer.FolderSwitch](https://learn.microsoft.com/en-us/office/vba/api/outlook.explorer.folderswitch)

判定処理は、フォルダーツリーの矢印キー移動などで連続して呼ばれても
重くならないよう、登録済みフォルダーの一覧を素早く引ける形で保持し、
対象外なら即座に処理を終える作りにする。

### フェーズ5：安全な復元機能

初回登録時に各検索フォルダーの元のビュー・フィルターを保存する
（フェーズ0の診断で「変更が固定されるタイプ」と分かった場合は特に重要。
「かけている間だけ反映されるタイプ」であれば、そもそも何も固定されて
いないため、実質「すべてモードに戻す」操作だけで元の見た目に戻る）。
`すべてモード` と `全設定を復元して停止` の二段階で、いつでも導入前の
表示へ戻せるようにする。

## VBA構成案

| モジュール | 役割 |
| ------------------------- | --------------------------- |
| `ThisOutlookSession` | Outlook起動時の初期見張り役設置、新規ウィンドウの検知 |
| `modSearchViewController` | 未読／すべて切替、フィルター適用、復元、対象フォルダーの高速判定 |
| `modSearchFolderRegistry` | 対象検索フォルダーと元ビューの保存・照合、専用ビュー化、Entry ID失効検知 |
| `clsExplorerWatcher` | 個々のOutlook画面（ウィンドウ）ごとのフォルダー切替を検知する見張り役。複数画面を開いた場合に画面の数だけ生成される |

## 用意する操作マクロ

* `登録：現在の検索フォルダー`（登録と同時に専用ビュー化を実施）
* `解除：現在の検索フォルダー`
* `未読モード：管理対象すべて`
* `すべてモード：管理対象すべて`
* `状態確認：管理対象一覧`（各フォルダーが有効か、Entry IDが失効していないかも表示）
* `緊急復元：元ビューへ戻して制御停止`

クイックアクセスツールバーへの登録は、Outlookの仕組み上プログラムから
自動ではできない。マクロ自体を用意した後、越智さんが初回に1回だけ
「その他のコマンド」→「マクロ」からピン留めする手順を導入ガイドとして
別途用意する。

## 重要な設計上の配慮

* **他フォルダーへの波及防止**：登録時に専用ビュー化を必ず行い、
  未登録フォルダー（受信トレイ・送信済み等）には一切触れない状態を
  構造的に保証する。
* **元フィルターの保全**：単純にフィルターを空にせず、各検索フォルダー
  本来のビュー条件を保存・復元する。
* **起動直後の一貫性**：Outlookを開いた瞬間に表示される最初の画面にも、
  フォルダー切替を待たずにモードを適用する。
* **軽量化**：フォルダーを開くたび全件走査せず、現在開いた一フォルダー
  だけを処理する。
* **誤作動防止**：通常の受信トレイ、送信済み、標準の「未読メール」検索
  フォルダーは初期状態で対象外とする。
* **Entry ID失効への耐性**：登録済みフォルダーが削除された場合は
  `状態確認：管理対象一覧` で無効表示にし、静かに壊れたままにしない。
* **セキュリティ**：マクロは署名し、`マクロをすべて有効化` は使わない。
  社内ポリシーに従い、署名済みマクロのみ実行できる状態にする。

## 検証計画

1. **（最優先・新規）** 1フォルダーだけでフィルター変更を試し、
   (a) 他の未登録フォルダー（受信トレイ等）に影響が及ばないこと、
   (b) 変更が「かけている間だけ反映」か「固定される」かのどちらの
   挙動かを確認する。
2. `NTAN` と `Flags` の2フォルダーだけで、専用ビュー化・登録・未読モードを試験。
3. フォルダー往復、**Outlook再起動直後に最初に開く画面**、未読／すべて
   切替を確認。
4. 2枚目のOutlookウィンドウを開いた状態でも、モードが同じように
   反映されることを確認。
5. 元の検索条件と件数が壊れていないこと、未登録フォルダーが無傷である
   ことを確認。
6. 合格後、残りのお気に入り検索フォルダーへ展開。
7. 緊急復元マクロで元ビューへ戻せることを確認。
8. クイックアクセスツールバーへのマクロ手動登録手順が問題なく行えることを確認。
