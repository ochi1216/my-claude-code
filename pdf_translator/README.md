# PDF Translator (Gemini API)

英語などのPDFをGoogle Gemini APIで翻訳し、レイアウト（文字の位置・フォントサイズ・
文字色・背景）をできる限り保持したまま翻訳版PDFを生成するデスクトップツール（tkinter GUI）。

`ppt_translation_20260309_03.py`（PowerPoint Gemini 翻訳ツール）のUI／進捗表示／
Gemini呼び出しロジック（自動モデル検出・タイムアウト・リトライ・フェイルファスト・
ロギング）を踏襲し、PDF向けにテキスト抽出・書き戻し部分を新規実装したもの。

## 必要要件

- Python 3.9以上
- Gemini APIキー（環境変数 `GEMINI_API_KEY` に設定）

## セットアップ手順

1. 依存パッケージをインストールする。

   ```
   pip install -r requirements.txt
   ```

2. 環境変数 `GEMINI_API_KEY` にAPIキーを設定する。

   ```
   # macOS/Linux
   export GEMINI_API_KEY="your-api-key"

   # Windows (PowerShell)
   setx GEMINI_API_KEY "your-api-key"
   ```

3. スクリプトを実行する。

   ```
   python pdf_translator_20260722_01.py
   ```

4. 「ファイル選択」から翻訳したいPDFを選び、翻訳先言語（日本語／英語／中国語簡体字）を
   選んで「翻訳開始」を押す。

5. 完了すると同じフォルダに `元ファイル名_ja.pdf`（英語翻訳なら `_en.pdf`）のように、
   末尾2文字の言語コード付きで保存される。

## 処理の仕組み

1. PyMuPDF (`fitz`) で各ページのテキストブロック（≒段落）を位置・フォントサイズ・
   文字色つきで抽出する。
2. 抽出したテキストを10件ずつバッチにまとめ、Gemini APIへ並列（最大3スレッド）で
   翻訳リクエストを送信する。
3. 各ブロックの元の矩形を墨消し（redaction）し、直前にサンプリングした背景色で
   塗り潰したうえで、翻訳文をフォントサイズを自動縮小しながら同じ矩形に再配置する。
4. 日本語／中国語（簡体字）／韓国語はPyMuPDF内蔵のCJKフォント（`japan` / `china-s` /
   `korea`）を使用するため、追加のフォントファイルは不要。

## 既知の制限

- **スキャン画像PDF（テキストレイヤーなし）は非対応。** OCR機能は今回のスコープ外。
- ブロック単位で翻訳するため、1つの文が複数ブロックに分割されているレイアウトでは
  文脈が失われ、不自然な訳になることがある（PPT版が「run」単位で翻訳するのと同様の
  トレードオフ）。
- 背景色はブロック左上近傍の1点サンプリングによる近似のため、グラデーションや
  画像上に重なったテキストでは背景と完全には一致しない場合がある。
- 翻訳文が元の矩形に収まりきらない場合、フォントサイズを4ptまで自動縮小するが、
  それでも収まらない場合ははみ出したまま挿入される（`translation_debug.log` に警告記録）。

## トラブルシューティング

- **`GEMINI_API_KEY が設定されていません`**: 環境変数を設定した後、ターミナル／
  アプリを再起動してから実行する。
- **`対象のPDFファイルが別のアプリで開かれています`**: PDF閲覧ソフトで対象ファイルを
  閉じてから再実行する。
- **`Gemini APIへの通信が3回連続で失敗しました`**: ネットワーク接続、またはAPIの
  レート制限を確認する。詳細は `translation_debug.log` を参照。
