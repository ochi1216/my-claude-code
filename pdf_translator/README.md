# PDF Translator (Gemini API)

英語などのPDFをGoogle Gemini APIで翻訳し、レイアウト（文字の位置・フォントサイズ・
文字色・背景）をできる限り保持したまま翻訳版PDFを生成するデスクトップツール（tkinter GUI）。

`ppt_translation_20260309_03.py`（PowerPoint Gemini 翻訳ツール）のUI／進捗表示／
Gemini呼び出しロジック（自動モデル検出・タイムアウト・リトライ・フェイルファスト・
ロギング）を踏襲し、PDF向けにテキスト抽出・書き戻し部分を新規実装したもの。

## 必要要件

- Python 3.9以上
- Gemini APIキー（環境変数 `GEMINI_API_KEY` に設定）

## セットアップ手順

### Windows（バッチファイルで起動する場合）

1. 環境変数 `GEMINI_API_KEY` にAPIキーを設定する（コマンドプロンプトで実行後、
   一度開き直す）。

   ```
   setx GEMINI_API_KEY "your-api-key"
   ```

2. `run_pdf_translator.bat` をダブルクリックする。初回は仮想環境(venv)の作成と
   依存パッケージのインストールが自動実行される（2回目以降は起動のみ）。
   フォルダ内に `pdf_translator_yyyymmdd_NN.py` が複数存在する場合は、
   ファイル名が最も新しいもの（＝最新バージョン）を自動的に起動する。

### 手動セットアップ（macOS/Linux/Windows共通）

1. 依存パッケージをインストールする。

   ```
   pip install -r requirements.txt
   ```

2. 環境変数 `GEMINI_API_KEY` にAPIキーを設定する。

   ```
   # macOS/Linux
   export GEMINI_API_KEY="your-api-key"

   # Windows (PowerShell)
   setx GEMINI_API_KEY "your-api-key"
   ```

3. スクリプトを実行する（`pdf_translator_yyyymmdd_NN.py` の最新版）。

   ```
   python pdf_translator_20260722_05.py
   ```

### 使い方

1. 「ファイル選択」から翻訳したいPDFを選び、翻訳先言語（日本語／英語／中国語簡体字）を
   選んで「翻訳開始」を押す（「表・グラフに重なるテキストを翻訳しない（安全重視）」は
   既定でOFF＝翻訳する。より安全性を優先したい場合のみONにする）。

2. 完了すると同じフォルダに `元ファイル名_ja.pdf`（英語翻訳なら `_en.pdf`）のように、
   末尾2文字の言語コード付きで保存される。

## 処理の仕組み（v04時点）

1. PyMuPDF (`fitz`) で各ページのベクター図形（罫線）を解析し、線分同士が実際に交差して
   いるかどうかでクラスタリングして「表のグリッド（セル境界）」を検出する。単に
   ページ内の全水平線・全垂直線を1つの座標集合として扱うと、離れた場所にあるグラフの
   辺まで表の列線と誤認識してセルがズレるため、実際に交差する線分だけを同じ表とみなす。
2. テキストはスパン単位（PyMuPDFの「ブロック」単位より細かい、フォント情報を持つ最小
   単位）で抽出し、罫線グリッドのセル矩形に収まるものはセル単位でグループ化する
   （表の同じ行にある隣接セルの文字が1つに混ざらないようにするため）。セルの外側に
   ある自由配置のテキストは、従来通りブロック単位（≒段落）でグループ化する。
3. 抽出したテキストを10件ずつバッチにまとめ、Gemini APIへ並列（最大3スレッド）で
   翻訳リクエストを送信する。
4. 表セルは罫線から検出した実際のセル矩形の内部だけを墨消し（redaction）し、罫線
   そのものには一切触れない。墨消し時は `images`/`graphics` を保護するオプションを
   指定し、矩形に重なる罫線・画像・チャート図形を一切消去・上書きしない。
5. 翻訳文は、罫線とテキストの間隔から推定した元の寄せ（左/中央/右）で、フォントサイズを
   自動縮小しながら再配置する。
6. 罫線グリッドとして認識できない図（チャートの凡例・軸ラベル等）に重なるテキストも、
   既定では翻訳する（v03までの墨消し破壊バグを修正済みのため）。翻訳網羅性より安全性を
   最優先したい場合は、GUIの「表・グラフに重なるテキストを翻訳しない」をONにすると、
   その部分は原文のまま保護される。
7. 日本語／中国語（簡体字）／韓国語はPyMuPDF内蔵のCJKフォント（`japan` / `china-s` /
   `korea`）を使用するため、追加のフォントファイルは不要。

## 既知の制限（技術的な原理限界。100%保証はできない領域）

- **スキャン画像PDF（テキストレイヤーなし）は非対応。** OCR機能は今回のスコープ外。
- 罫線で囲まれていない自由配置の図（チャートの凡例・軸ラベル等）に重なるテキストも
  既定では翻訳される。可変長の翻訳文を固定レイアウトの図形に安全に収める一般解は
  存在しないため、狭い図形の中の文字などでは稀にレイアウトが窮屈になることがある
  （実装のバグではなく、PDFという形式そのものの制約）。気になる場合は「表・グラフに
  重なるテキストを翻訳しない」をONにすると、その部分は原文のまま保護される。
- 表セル以外の自由テキスト（段落等）は、1つの文が複数ブロックに分割されている場合に
  文脈が失われ、不自然な訳になることがある。
- 表セル以外の自由テキストの背景色はブロック付近の1点サンプリングによる近似のため、
  グラデーション等では完全には一致しない場合がある。
- 翻訳文が元の矩形に収まりきらない場合、フォントサイズを4ptまで自動縮小するが、
  それでも収まらない場合ははみ出したまま挿入される（`translation_debug.log` に警告記録）。

## トラブルシューティング

- **`GEMINI_API_KEY が設定されていません`**: 環境変数を設定した後、ターミナル／
  アプリを再起動してから実行する。
- **`対象のPDFファイルが別のアプリで開かれています`**: PDF閲覧ソフトで対象ファイルを
  閉じてから再実行する。
- **`Gemini APIへの通信が3回連続で失敗しました`**: ネットワーク接続、またはAPIの
  レート制限を確認する。詳細は `translation_debug.log` を参照。
