# Mail Template Manager

定型メール（月次レポート等）を**カード**として管理し、その月のSharePointフォルダ／
ファイルのリンクを自動で解決して、Outlookの下書きを組み立てるツール。

**現在の状態：M0（実機プローブ）のみ実装済み。** 本体はまだありません。

## M0：実機プローブの実行手順（越智さんへのお願い）

### 何をするものか

このツールを作るにあたって、**越智さんの会社PCでしか確かめられないこと**が9項目あります。
それを1回だけ測るための診断です。

- **メールのウィンドウが1つ開く場合があります**
- **何も送信しません**（送信するコードが1行も存在しないことを自動テストで担保しています）
- **作成したメールは自動で削除します**
- **所要30秒ほどです**

### 手順

1. このフォルダごと会社PCにコピーします。
2. `run_probe.bat` を**ダブルクリック**します。
3. 画面に結果が表示され、同じフォルダに2つのファイルができます。
4. 最後の案内に従って、次の2つのファイルを送ってください。
   - `probe_result_YYYYMMDD_HHMM.txt` … 診断結果
   - `probe_signature.html` … Outlookが自動で入れる署名の実物
5. 結果の中に `[お願い]` と書かれた質問が数点あります。あわせてお答えください
   （人にしか答えられないことだけを聞いています）。

### うまくいかないとき

- **`pywin32 が入っていません` と出た場合**：画面の案内どおり
  `pip install pywin32` を実行してから、もう一度 `run_probe.bat` を実行してください。
  この場合、結果ファイルは送っていただかなくて結構です。
- **黒い画面が一瞬で消える場合**：`run_probe.bat` を右クリック →「編集」で中身が
  見えれば、ファイル自体は壊れていません。コマンドプロンプトから
  `python probe_outlook.py` を直接実行して、出たメッセージをお知らせください。
- **どれかの項目が `[NG]` だった場合**：**問題ありません。**
  設計をそれに合わせるための調査です。越智さんの追加作業は発生しません。

### SharePointの確認（項目[9]）について

例1の上位フォルダURLをいただけたら `config.json` に設定して測ります。
未設定のうちは項目[9]だけスキップし、他の8項目は通常どおり実行します。

```
copy config.example.json config.json
```
としたうえで、`probe_target_folder_url` にブラウザのアドレスバーの値を貼ってください。

`tenant_id` / `client_id` は**空のままで構いません**。`po_database_organizer` の
`config.json` から自動的に借用します（読むだけで書き換えません）。
**新規のEntra ID権限申請は発生しません**（要求スコープは `Sites.Read.All` のみ）。

## 開発者向け

### 検証ハーネス

```
python tests/run_tests.py
```

Outlook・ネットワーク・Graph APIに一切アクセスしないため、会社PC・開発環境
（Claude Code Web / Linux）のどちらでもそのまま実行できます。

`probe_outlook.py` は **win32com をトップレベルで import しない**構造にしてあり、
HTML組み立て・レポート整形・例外分離・認証情報の借用はWindows以外でも検証できます。
Outlook実機の動作だけは、このハーネスでは検証できません（`run_probe.bat` で確認します）。

### バージョン管理について

`probe_outlook.py` は機能ツールではなく1回限りの診断スクリプトのため、
リポジトリ規約の `ツール名_yyyymmdd_NN.py` 形式の**バージョン管理対象外**とします
（`outlook_total_organizer/diagnose_archive.py` と同じ扱い）。
M1以降の本体は `mail_template_manager_yyyymmdd_NN.py` として規約どおり管理します。

### コミットしないもの

`config.json` / `token_cache.json` / `cards/` / `contacts.json` /
プローブの出力（`probe_result_*.txt`, `probe_signature.html`, `probe_sample.eml`）は
実在の宛先アドレス・サイトURL・署名（氏名や連絡先）を含むため、`.gitignore` で
除外しています。コミット対象は `config.example.json` などのテンプレートのみです。
